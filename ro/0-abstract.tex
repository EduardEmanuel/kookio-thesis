\chapter*{Rezumat}

Această lucrare prezintă proiectarea și implementarea unei aplicații web full-stack, denumite \textit{Kookio}, realizată ca studiu de caz pentru analiza arhitecturii \textbf{PAN} (Prisma--Analog--Nx) în contextul aplicațiilor web moderne.
Aplicația are ca obiectiv gestionarea inventarului de ingrediente pentru utilizatori casnici, contribuind indirect la reducerea risipei alimentare printr-o organizare mai eficientă a resurselor disponibile.

Motivația lucrării derivă din necesitatea adoptării unor arhitecturi web capabile să ofere performanță ridicată, coerență între frontend și backend și un proces de dezvoltare unitar.
În acest cadru, lucrarea investighează arhitectura PAN ca model full-stack bazat pe ecosistemul TypeScript, în care straturile aplicației sunt integrate într-un flux comun de dezvoltare.

Aplicația utilizează randare server-side cu Angular prin framework-ul Analog, comunicare type-safe între client și server prin tRPC și persistența datelor prin Prisma și CockroachDB.
Organizarea proiectului într-un monorepo gestionat cu Nx facilitează modularitatea, testarea automată și execuția incrementală a task-urilor.

Implementarea este validată prin testare automată unitară și end-to-end, folosind Vitest și Playwright, precum și prin rularea aplicației într-un mediu modern de deployment.
Rezultatele obținute indică faptul că arhitectura PAN constituie un model viabil pentru dezvoltarea aplicațiilor web full-stack scalabile, coerente și extensibile.
