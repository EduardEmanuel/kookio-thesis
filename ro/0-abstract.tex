\chapter*{Rezumat}

\begin{abstract}
Această lucrare prezintă proiectarea și implementarea unei aplicații web full-stack, denumite \textit{Kookio}, realizată ca studiu de caz pentru analizarea arhitecturii \textbf{PAN} (Prisma--Analog--Nx) în contextul aplicațiilor web moderne.
Aplicația are ca scop gestionarea inventarului de ingrediente pentru utilizatori casnici, contribuind indirect la reducerea risipei alimentare printr-o mai bună organizare a resurselor disponibile.

Motivația lucrării pornește de la necesitatea utilizării unor arhitecturi web care să ofere performanță ridicată, coerență între frontend și backend și o experiență de dezvoltare unitară.
În acest context, lucrarea investighează arhitectura PAN ca model full-stack bazat pe ecosistemul TypeScript, în care straturile aplicației sunt integrate într-un flux comun de dezvoltare.

Aplicația este realizată folosind randare server-side cu Angular prin framework-ul Analog, comunicare type-safe între client și server prin tRPC și persistența datelor cu Prisma și CockroachDB.
Organizarea proiectului într-un monorepo Nx permite modularitate, testare automată și execuție incrementală a task-urilor.

Implementarea este validată prin testare automată unitară și end-to-end, utilizând Vitest și Playwright, precum și prin rularea aplicației într-un mediu de deployment modern.
Rezultatele obținute demonstrează că arhitectura PAN reprezintă un model viabil pentru dezvoltarea aplicațiilor web full-stack scalabile, coerente și extensibile.
\end{abstract}
